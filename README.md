# ServeEase - Local Home Service Platform

ServeEase is a local home-service platform that helps users find and book trusted service providers.

## Services

- AC Repair & Service
- Carpenter
- Electrician
- Home Salon Services
- House Cleaning
- Painter
- Plumber
- Washing Machine & Refrigerator Repair

## Features

- Easy service selection
- Provider and time selection
- Transparent pricing
- Verified service providers
- Transparent ratings
- Fair pricing
- User-friendly interface

## Technologies Used

- React
- JavaScript
- HTML
- CSS
